# WHY old-framework-3.x AND NOT main.  Upstream deprecated RISCOF: the default

# model plus a UDB configuration.  Plan A10 asks for RISCOF specifically and for

# RISCOF's Python dependencies need PINNING, and the reason is a real bind:
#
#   * riscof 1.25.3 (current) declares gitpython==3.1.17, which predates
#     Python 3.12 and will not install on this venv's 3.13.  The pin is stale
#     rather than meaningful -- riscof uses GitPython for a version string --
#     so it is installed with --no-deps alongside a current GitPython.
#   * riscof 1.21.1, which uv picks when resolving normally, imports
#     riscv_config.warl.warl_interpreter.  That was removed in riscv-config
#     3.0.0, so 1.21.1 needs riscv-config 2.x -- and riscv-config 2.x rejects
#     the ISA schema this project's yaml is written in.  1.25.3 --no-deps is
#     the combination that works.
#
# Install:
#   UV=toolchain/opt/uv-x86_64-unknown-linux-gnu/uv
#   $UV pip install --python .venv/bin/python riscv-config==3.18.3 riscv-isac
#   $UV pip install --no-deps --python .venv/bin/python riscof==1.25.3
